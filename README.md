# Article To ACS Sensors - Closed-loop temperature modulated potentiometry of symmetric printed Ag/AgCl cell for reference half-cell compensation of field deployable potentiometric measurement
Reliable, field-deployable electrochemical sensing requires low-cost reference electrodes whose response to environmental changes are stable and reproducible. Traditional liquid junction references are mechanically complex and suffer from drift that makes them unreliable outside the laboratory.
